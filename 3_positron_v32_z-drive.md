## 2. Installation

### Install the Planetary Shaft and Gears
- Install an MF148ZZ bearing into the hole of the main body.
- Insert the planetary carrier shaft into the hole.
- Place MR85ZZ bearings onto the feet of the planetary carrier shaft.
- Add a planetary gear onto each bearing.

### Cover the Planeraty Gearbox Cover
- Put the planetary gearbox cover on.
- Be carefull when placing the cover. You need to slightly twist the cover to make the cover and gears fit. Please twist the shaft two full rotations after finishing placing the cover. If it moves smoothly, this means a successful installation.

| | |
|:-:|:-:|
| [![0009-9](img/3/0009-9.preview.png)](img/3/0009-9.png) | [![0010-5](img/3/0010-5.preview.png)](img/3/0010-5.png) |

### Add the Z Motor
- Attach the Z motor to the planetary gearbox cover.
- The motor cable should go through the slot.
- Install the 5x6mm pulley into the shaft. Please remember to leave a small gap so that the pulley doesn't rub on the printed part.
- Install one M3x3 set screw to the shaft on the flat side and install one set screw into another hole of the pulley. (The set screws should be pre-applied with Threadlocker.)
- Please twist the pulley two full rotations after installing the set screw. If it moves smoothly, this means a successful installation.
- Add an MR85ZZ bearing onto the pulley.

- Route the 6mm belt as shown in the pictures. We will wire the belt to the Z column in a later step.

### Install Motor Bracket
- Attach the motor bracket to the motor as shown in the picture.
- The motor cable should go as shown in the picture. Route it before you secure the whole part with screws. (This picture is just to show how the wire goes. The printed part is not the most up-to-date one.)
- Secure the printed parts with below screws. Use an M3x25 BHCS screw in the upper left hole (tapped directly into the hole). Use an M3x20 BHCS screw in the bottom middle hole (tapped directly into the hole. Use an M3x8 BHCS screw in the bottom right hole.
