## 2. Installation

> For all the M2.5 screws, please use our screwdriver included in the kit.

### Install Standoffs
- Turn over the base plate and insert M3x8 BHCS screws through the holes as shown in the picture. Secure M3x8x7x10 standoffs into the screws.
- Install M2.5x4+4 standoffs in the indicated holes.

### Install the Switch PCB Mount
- Install M2.5x3x4 heatset inserts into holes of the printed mount.
- Position the switch PCB mount onto the base plate. Secure the mount with M3x6 BHCS screws.
- The goove on the base plate is designed to allow for a built-in power supply for future upgrades. The switch PCB mount is to fill the groove.
- Position the motor plate standoffs as shown in the picture.
- Secure with M3x8 BHCS from the back of the base plate.

### Prepare the Motors
- Put the motor plates on top of the motors and secure with M3x6 BHCS screws.
- Refer to the picture for wire orientation. The left is motor A and the right is motor B.
- Use pulley alignment tool to help you position the 5x3mm pulley.
- Install an M3x3 set screw to the shaft on the flat side.
- Install the H4.75xM3x5+6 hex standoffs in the indicated holes.
- Prepare A and B motor symmetrically.

### Prepare Side Panels
- Install M2.5x3x4 heatset inserts into the holes of left panels as shown in the picture.
- Install M2.5x3x4 heatset inserts into the holes of right panels as shown in the picture.
- Install the fish bone grills to the panels. Please use a dab of glue to keep them in place.
- There are two types of grills you can use, fish bone grills and slanted grills. Either will do.
- Pay attention to the the direction of the grills which should be in accordance with the direction of the fans so that the wind can flow in.
- Position the fan with 180mm wire onto the front left side panel. Secure with M2.5x14 BHCS screws.
- Position the fan with 40mm wire onto the front right side panel. Secure with M2.5x14 BHCS screws.

### Install the Linear Rail
- Position the linear rail to the standoffs and align the holes. Secure the linear rail with M3x8 SHCS screws.
- The kit comes with greased rails from batch 2. If you find your rails are not greased, remember to grease it beforehand. How to check if it is greased: Wipe the rail gently with a clean cloth or tissue. If it feels slightly oily or you see a thin, shiny layer on the surface, the rail is greased. If it looks dry or the cloth stays clean, it likely needs lubrication.

### Install the Z Joint Base Block
- Position the Z joint base block to the base plate. Secure it to the tensioner block using an M3x25 SHCS screw.
- Leave 4mm gap between the tensioner block and the base block. It is used for belt tensioning in a later step.
- Apply some grease in the indicated area on both sides of the base block. It is ok not to grease the surface but please do grease the slots, which will make folding and unfolding process more smoothly.
- Turn over the base plate and secure with M4x10 BHCS screws.
